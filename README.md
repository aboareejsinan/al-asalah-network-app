# شبكة الأصالة - Al Asalah Digital Gateway

تطبيق ويب حديث لشبكة الأصالة الرقمية للبث التلفزيوني الأرضي (DVB-T2).

## المميزات الرئيسية
- **الشاشة الرئيسية**: عرض تفاصيل الاشتراك، التنبيهات، القنوات المميزة، والخدمات السريعة.
- **اشتراكي وتفاصيل الاشتراك**: متابعة حالة الاشتراك، تاريخ البدء والانتهاء، والمدة المتبقية.
- **تجديد الاشتراك**: اختيار باقة التجديد ووسيلة الدفع المناسبة.
- **إتمام الدفع وإثبات السداد**: عرض بيانات الحساب المصرفي وخاصية نسخ رقم الحساب، مع إمكانية إرفاق صورة إيصال التحويل ورقم العملية.
- **سجل العمليات**: تتبع ومتابعة طلبات التجديد وحالتها (قيد المراجعة).
- **القنوات وتفاصيل الباقات**: استعراض الباقات المفتوحة والمشفرة وتصنيفاتها وقنواتها.
- **الترددات والتغطية**: بيانات الترددات التفصيلية لأبراج الصمدة والهيئة، ومناطق التغطية في محافظة مأرب.
- **دليل الاستقبال ومواصفات الرسيفر**: دليل إرشادي شامل لاستقبال البث الأرضي الرقمي والأجهزة والبطاقات المتوافقة.
- **الدعم الفني والأسئلة الشائعة**: فتح بلاغات فنية، أسئلة وأجوبة تفاعلية، وقنوات التواصل المباشرة عبر الواتساب والهاتف.
- **الإشعارات وحسابي**: مركز الإشعارات وإدارة الحساب والبطاقة الذكية.
